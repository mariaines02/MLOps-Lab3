# MLOps Lab 3: Hugging Face Branch

This branch (`hf-space`) is dedicated to the **Hugging Face Space** deployment.

It contains the **Frontend** application (`app.py`) which serves as the user interface for the MLOps Lab 3 project. This interface communicates with the backend API hosted on Render.

**Note**: The main project code and backend logic are located in the `main` branch.
